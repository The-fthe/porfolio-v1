下部のボタンで案を切り替え、「この案を選ぶ」で候補を表示します。選択はページ内だけに保持され、保存や本番への反映は行いません。採用する案名をチャットに伝えてください。案の矢印操作は切り替えバー内に限定し、Cの作品タブでは矢印・Home・Endで作品を選べます。

## ローカルで開く

プロジェクトルート `D:/js/porfolio-v1` で実行します。

```powershell
npm --prefix github-pages/portfolio-prototype run preview
```

既定の接続先は `http://127.0.0.1:42036/`。現在は非表示のプレビューサーバーが起動済みです。各案へ直接進むには `?variant=A`、`?variant=B`、`?variant=C` を付けます。

HTML・CSS・JavaScriptとローカル素材だけの静的ページです。プレビューサーバーはNode.jsを使用しますが、配信時のフレームワークやサーバー実行環境への依存はありません。素材参照は相対パスのため、GitHub Pagesのサブディレクトリでも配置できます。候補ごとの値と構成は [DESIGN.md](./DESIGN.md) に記録しています。
